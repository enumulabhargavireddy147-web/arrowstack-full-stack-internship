# Final Presentation

`Arrowstack-Internship-Presentation.html` is the final presentation covering all three projects.

Open it in any browser (Chrome, Edge, Firefox, Safari) and present full screen.

- **← / →** or **space** — next / previous slide
- **T** — toggle the thumbnail rail
- **F** — full screen

It is a single self-contained file: fonts, styles and the slide engine are embedded, so it works
offline and behind proxies with no install. There are 16 slides: a cover and contents, one section
per project, then the shared engineering standard, the validation results, the stack decisions, the
roadmap and the close.
